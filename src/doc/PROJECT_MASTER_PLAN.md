# Startup Incubator Platform

## Project Overview

A production-ready Startup Incubator Platform built using React, Tailwind CSS, Spring Boot, and MySQL.

---

## Tech Stack

### Frontend
- React 19
- Vite
- Tailwind CSS v4
- React Router DOM
- Framer Motion
- Lucide React
- Axios

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL
- JPA / Hibernate
